# Copilot Access Policy

## File Access Rules

⚠️ **IMPORTANT**: The following files should ONLY be accessed when explicitly requested:

### 🔒 Sensitive/Secret Files (Auto-Excluded)
- `application-secret.yml` - Database credentials and API keys
- `application-local.yml` - Local environment configuration
- `.env` - Environment variables
- `*.enc` - Encrypted files
- `*.key` - Cryptographic keys
- `*.pem` - Certificate files
- `.secrets/` - Any secrets directory
- `secrets/` - Any secrets directory

### ✅ Safe to Auto-Access
- `.gitignore` - Project configuration
- `pom.xml` - Maven dependencies
- `Dockerfile` & `docker-compose.yml` - Container configuration
- Source code in `src/main/java/` and `src/test/java/`
- Configuration files that don't contain secrets

## Guidelines for the Assistant

1. **Never explore sensitive files** unless explicitly mentioned
2. **Skip files in `.gitignore`** when gathering context
3. **Ask before reading** unfamiliar file types
4. **Only edit files you're directly asked to edit**
5. **Report any access to sensitive files** immediately

## Questions?
If unsure about file access, ask the user first.
